# 当前方法与实现一致性审计

审计更新：2026-09-01

## 结论

当前论文候选主配置为 `uniform + locked + task_supported ARG + rank_adaptive`。它不再以延迟信用选择Task/VLM权重。延迟统计仍会为检查点兼容而计算和保存，但在 `uniform` 路径中不改变即时共识、记忆目标或训练损失。

## 第一阶段：双视角共识记忆

| 核对项 | 代码行为 | 论文描述 |
|---|---|---|
| 初始记忆 | Task/VLM完整概率0.5/0.5平均 | 一致 |
| 当前共识 | 始终0.5/0.5，不用延迟损失改权重 | 一致 |
| 可靠性 | 当前双视角一致性 × 当前共识相对历史记忆的稳定性 | 一致 |
| 更新率 | `mu * (0.5 + 0.5 * reliability)` | 一致 |
| 记忆覆盖 | 所有样本都更新，不按阈值删除 | 一致 |
| 首轮行为 | 使用初始记忆；从第二轮扫描开始更新 | 一致 |
| 先验校准 | 只在前4轮影响硬伪标签，不影响全分布记忆 | 一致 |
| 冲突硬监督 | 使用记忆Top-1，权重0.05 | 一致 |
| 一致硬监督 | 使用两路校准概率和的Top-1，权重0.4 | 一致 |
| VLM训练 | 冻结视觉和文本编码器，只训练prompt | 一致 |

## Rank-adaptive对齐

训练开始时用配置批大小 (B) 和类别数 (C) 计算 `min(B,C)/C`，全局阈值为0.75：

- 覆盖率不低于0.75：使用batch IIC，多样性权重0.1；
- 覆盖率低于0.75：使用逐样本分布交叉熵，多样性权重0；
- 分支整次运行固定，不因最后一个短batch改变；
- 规则不读取数据集名称或目标标签。

批大小64时，Office-Home和VisDA-C使用IIC，DomainNet-126使用逐样本对齐。

## 状态交接与第二阶段

| 核对项 | 代码行为 | 论文描述 |
|---|---|---|
| 交接内容 | F/B/C与逐样本全分布记忆 | 一致 |
| 不交接内容 | 第一阶段prompt和两个优化器状态 | 一致 |
| Task更新 | 冻结C，更新F/B | 一致 |
| VLM更新 | 从预训练权重重建；冻结文本侧，更新视觉侧 | 一致 |
| 冲突记忆 | `locked`：冲突保留旧记忆，一致接受候选更新 | 一致 |
| 硬准入 | 冲突新增比例为0；一致准入mask跨周期累积 | 一致 |
| 硬标签 | 已准入样本每周期按当前两路平均概率重算 | 一致 |
| ARG | 只对未准入冲突生效；记忆支持Task时替换VLM软目标 | 一致 |
| Task损失 | consistency 0.2、hard CE 0.4、KL 0.4 | 一致 |
| 周期顺序 | 全量扫描固定监督，更新一遍VLM视觉侧，再训练F/B 4 epochs | 一致 |

目标标签只用于准确率日志和训练结束后的离线峰值汇总，不进入损失、伪标签、分支选择或提前停止。峰值是事后oracle指标，必须同时报告固定最终值。

## 消融语义边界

1. 早期 `dcm_uniform` 仍包含完整记忆，不能称为“w/o DCM”。
2. ARG关闭后，`locked`和`writable`不会改变当前训练监督，因此不能用这组对照证明CLM独立有效。
3. 现有四任务证据直接支持ARG；CLM应解释为ARG所读历史目标的保护机制。
4. VisDA-C上当前等权配置比同预算延迟信用变体低0.09个百分点，不能宣称等权在所有数据集上都更优。
