# DCR-SFDA四任务交互消融审计

审计更新：2026-09-01
数据源：`data/dcr_sfda_ablation_summary_seed2020.csv`

## 范围和协议

- 随机种子：2020。
- 任务：A→C、C→P、P→R和R→A。该四任务环在运行前固定，每个Office-Home域各作一次源域和目标域。
- 训练长度：第一阶段15 epochs，第二阶段4 cycles × 4 epochs，共31次任务模型目标集训练遍历。
- 每个任务均有16条评估记录，同时保留固定最终值和训练区间内事后峰值。
- 目标标签只用于离线准确率，不参与融合模式、冲突写入方式、ARG、模型参数或阈值选择。

## 变体语义修正

早期开发名不能直接作为论文模块名：

- `full`：延迟信用 + 冲突锁定 + ARG。
- `dcm_uniform`：等权 + 冲突锁定 + ARG。它仍维护全分布记忆，因此不能称为“w/o DCM”；当前将其作为统一候选配置。
- `clm_writable`：延迟信用 + 冲突可写 + ARG。它只改变第二阶段写入规则。
- `arg_none`：延迟信用 + 冲突锁定 + 无ARG。
- `uniform_writable`：等权 + 冲突可写 + ARG。
- `uniform_writable_arg_none`：等权 + 冲突可写 + 无ARG。
- `uniform_arg_none`：等权 + 冲突锁定 + 无ARG。

## 汇总结果

|---|---|---|:---:|---:|---:|---:|

## 可支持的结论

1. ARG是当前证据最明确的部分。等权锁定底座关闭ARG后，四任务固定最终平均下降0.96个百分点；在延迟信用锁定和等权可写底座上，ARG也分别带来0.62和0.88个百分点。
2. 冲突锁定的独立平均效应很小且依赖融合模式：等权下锁定比可写高0.08个百分点，延迟信用下锁定反而低0.13个百分点。因此不能宣称CLM已被证明独立提升准确率。
3. 等权无ARG的锁定与可写结果完全相同。这与实现一致：ARG关闭后，第二阶段软监督不读取冲突记忆，冲突写入方式不会改变训练输出。
4. 等权锁定ARG在该四任务环上比延迟信用锁定ARG高0.29个百分点，但VisDA-C迁移检查低0.09个百分点。现有证据不足以宣称等权融合在所有数据集上普遍更优。
5. 四任务和单一随机种子不能替代Office-Home全12任务、多种子和有效机制内部消融。
