# DUET-DAC-260823-001: Delayed Agreement Credit

## 定位

COSMO 可以在 related work 中引用，也作为“全分布、全覆盖、双分支同步学习”的强对照，但本实验不使用它的核心教师构造：

- 不使用 entropy-weighted product of experts (PoE)；
- 不使用固定的初始 consensus anchor；
- 不使用 entropy-rank CSM；
- 不使用第三个视觉模型、Comparator 或目标 GT。

89.35% 的 `duet_anchored_consensus` 保留为成功控制组，不修改其教师逻辑。

## 已有证据与问题

历史 Comparator 实验表明：后续达成一致的 matured conflict 能形成高精度信号，但把这批容易样本用来训练路由器，再泛化到当前困难 conflict，有明显 easy-to-hard 错位。

本次改为：样本 `i` 的历史只决定样本 `i` 的 Task/CLIP 权重，不再学一个跨样本路由器。

## 方法

对每个样本维护：

- 上一轮 Task/CLIP 完整 K 类分布；
- Task/CLIP 各自的折扣历史预测损失；
- 连续的专家权重；
- 持续更新的完整分布 memory。

第 `e` 轮扫描后，用当前 Task/CLIP 算术平均作为新观测，回看上一轮哪个专家预测得更接近。使用归一化 JS divergence 记账，再根据折扣平均历史损失计算每个样本的专家权重。所有样本都进入连续 memory 更新，无硬阈值和 abstain。

DUET 原有高质量 agreement hard label 继续保留；conflict hard label 和两分支 soft IIC 共同使用延迟记账 memory。

## 首次实验协议

- 数据：VisDA-C 固定 class-proportional proxy25；
- adaptation：13,847 张；
- evaluation：完整 55,388 张；
- seed：2020；
- 15 epochs，不使用 GT early stopping；
- 除教师构造外，学习率和 loss 系数与 89.35% 的成功控制组保持一致。

对照：原 DUET proxy25 = 87.93%，anchored consensus = 89.35%。

第一次只验证新教师构造是否有效，不同时扫参。若结果接近或超过 89.35%，说明自身创新路线值得继续；若回落到约 87.93%，则说明当前增益主要依赖 anchored PoE/CSM，需要换历史证据的使用方式，不应通过事后 GT 调参掩盖。

## 全量结果后的 handoff rescue

proxy25 的正确对照是 DUET 4 cycles x 4 passes 的 87.93%；90.36% 是 selected mixed pseudo-label precision，不是最终模型 ACC。全量 DUET 在 Cycle 4/8 为约 90.33%，Cycle 8/8 为 91.50%。

全量 DAC 在约同预算的第 13–15 轮达到约 90.7%，高于 DUET Cycle 4，但其两分支已趋于一致，继续 DAC 不再产生新证据。因此不做 32-epoch DAC，改为固定两阶段：

1. 使用已完成的 15-epoch DAC 最终 Task checkpoint，不用 GT 选择中间轮次；
2. 把 DAC `target_F/B/C.pt` 作为原 DUET 的初始 Task；
3. 原样运行发布版 DUET 4 cycles x 4 passes，重新引入周期伪标签和独立 CLIP 更新。首次31-pass handoff 的固定最终结果为 91.54%，Cycle 4 轨迹为 `91.38 -> 91.47 -> 91.52 -> 91.54`；
4. 根据早期结构消融中“adapted target head 下降约0.15–0.18点”的已知结果，下一版不增加 epoch，改为只 handoff DAC `target_F/B`，而 classifier C 必须使用未修改的 source checkpoint 并在 DUET 中继续冻结。总 Task passes 仍为31，最终 F/B/C checkpoint 必须保存。

这个实验验证的不是无限增加 epoch，而是 DAC 是否能作为更好的快速初始化，再由 DUET 恢复后期的独立证据和伪标签刷新。运行入口为 `tools/run_visda_dac_duet_handoff_full.sh`。
