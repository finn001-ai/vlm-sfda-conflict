# 项目目录

本目录只保留三个主要入口：

- `duet-sfda-main/`：当前可运行代码、配置与运行说明；
- `manuscripts/`：论文、综述与旧稿；
- `archive/`：历史实验、旧方案和结果归档。

当前论文主稿位于 `manuscripts/dac_handoff/manuscript_zh.md`，引用库位于 `manuscripts/dac_handoff/references.bib`。

## 目录约定

- 新代码和运行脚本只放入 `duet-sfda-main/`；
- 新论文内容放入 `manuscripts/` 对应子目录；
- 不再使用的实验结果、技术路线和交接记录移入 `archive/`，不直接删除；
- 原始数据和模型权重不纳入 Git，由代码目录中的运行说明记录路径。
